// holdings enrichment
Yahoo-side enrichment looks up each holding's ticker on Yahoo and fills in facets the row doesn't already carry. Two paths use this list:
  • Yahoo top-10 fetch — the rows are freshly minted, so every ticked field is populated.
  • Enrich through Yahoo button on the fund's holdings tile — only fills BLANK cells, so a manually uploaded holdings list is never overwritten.

Lookups are cached for 90 days per ticker and shared across funds — every fund holding AAPL benefits from a single lookup. Tick the fields you want enriched.
// portfolio holdings
On the portfolio's Holdings sub-tab, the same underlying holding held by two or more funds is merged into a single row. This setting picks which field decides that two positions are "the same holding". Ticker is the most reliable; ISIN is exact but often blank on Yahoo top-10 rows; Name matches on a normalised form (case- and spacing-insensitive) but is not fuzzy. A blank value for the chosen field never matches — each such holding stays its own row.
Applies to every portfolio. Changing it re-aggregates the Holdings sub-tab the next time it's opened.

Upload holdings

Tell PorxPy where the holdings file lives. The same field accepts either a download URL or a local filesystem path:
  • URL — e.g. an iShares product-page CSV link (https://www.ishares.com/.../holdings.csv). The server fetches it directly.
  • Local path — e.g. C:\Users\me\Downloads\AGGH.xlsx or /home/me/funds/aggh.csv, or the same as a file:// URI. The server reads it from disk.
Whatever you enter is remembered per fund — next time you open this dialog it'll be prefilled.
Match each PorxPy field to a column in your file. Required fields are marked with *; for any field your file doesn't contain, choose (none).
For Sector / Country / Currency / Asset class, when the dropdown is (none) you can either type a default value applied to every row, or click 📥 Yahoo to fetch the field per holding from Yahoo Finance (requires a Ticker column). Yahoo wins where it has data; the default fills any remaining gaps.

Upload breakdown CSV

Upload a CSV with three columns — facet, key, weight — covering any subset of asset class, sector, country, and currency. Weights may be percent (0–100) or fraction (0–1); the parser auto-detects per facet. Duplicate (facet, key) pairs are summed. After upload, the matching breakdown card gets a third source option ("Upload") you can switch to.

Example header row: facet,key,weight. Re-uploading replaces the previous CSV for this fund.
Map unrecognised facet columns
Pick which canonical facet each one means. The rows in that facet column will be re-processed with the canonical facet applied.
Map unrecognised key values
Each value must map to a canonical key from PorxPy's vocabulary. If a sensible canonical doesn't exist, edit the CSV to remove or rename the row and re-upload.

Edit exposure targets

Set target percentages for the buckets you care about. Buckets you don't add are "untargeted" — the portfolio's actual exposure in those buckets is summarised separately. Targets across a facet don't have to sum to 100%; whatever is left over is just untargeted.
